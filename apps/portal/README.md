# @wsc/portal

Next.js UI портала WSC (auth shell, sidebar, каталог, in-app workspace stub).

## Запуск

Из корня monorepo:

```bash
pnpm install
pnpm --filter @wsc/portal dev
```

Или `pnpm dev` (turbo поднимет все apps, включая portal).

URL: **http://localhost:3000**

Demo login: `demo@wsc.local` / любой пароль.
